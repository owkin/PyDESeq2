# Citing PyDESeq2

If you use PyDESeq2, please cite the PyDESeq2 paper {cite:p}`muzellec2023pydeseq2` and the original DESeq2 method {cite:p}`love2014moderated` it reimplements:

```bibtex
@article{muzellec2023pydeseq2,
    author  = {Muzellec, Boris and Telenczuk, Maria and Cabeli, Vincent and Andreux, Mathieu},
    title   = {PyDESeq2: a python package for bulk RNA-seq differential expression analysis},
    journal = {Bioinformatics},
    year    = {2023},
    volume  = {39},
    number  = {9},
    pages   = {btad547},
    doi     = {10.1093/bioinformatics/btad547}
}
```

If you use the log fold-change shrinkage step, please also cite apeGLM {cite:p}`zhu2019heavy`.

PyDESeq2 is part of the scverse ecosystem; please cite scverse as well {cite:p}`virshup2023scverse`.
